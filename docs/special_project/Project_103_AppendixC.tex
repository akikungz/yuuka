\section{การติดตั้งและใช้งาน Cloud-Based Platform}
\hspace*{1.3em}
การติดตั้งและใช้งานระบบในฉบับพัฒนาปัจจุบันควรมองเป็นการเตรียม \textbf{workspace แบบหลายรีโพซิทอรี} มากกว่าการติดตั้งโปรเจกต์เดี่ยว เนื่องจากบริการหลักและบริการประกอบถูกแยกออกจากกันตามขอบเขตความรับผิดชอบของแต่ละส่วน

\vspace{0.5em}
\textbf{ข้อกำหนดของระบบ (System Requirements)}
\vspace{0.5em}

\begin{mycustomenum2}
    \item \textbf{ซอฟต์แวร์ที่จำเป็น}
    \begin{mycustomenum2}
        \item Bun 1.3 หรือสูงกว่า
        \item Docker พร้อม Docker Compose Plugin
        \item PostgreSQL 15 หรือสูงกว่า
        \item Redis 7 หรือสูงกว่า
        \item Proxmox VE สำหรับการทดสอบงานที่เกี่ยวข้องกับ VM จริง
    \end{mycustomenum2}
    \item \textbf{ฮาร์ดแวร์ขั้นต่ำ}
    \begin{mycustomenum2}
        \item RAM อย่างน้อย 8 GB และแนะนำ 16 GB หรือมากกว่า
        \item CPU อย่างน้อย 4 cores
        \item พื้นที่จัดเก็บข้อมูลอย่างน้อย 50 GB
        \item การเชื่อมต่อเครือข่ายที่เสถียร
    \end{mycustomenum2}
\end{mycustomenum2}

\section{การเตรียมไฟล์ Environment}
\hspace*{1.3em}
ไฟล์ตัวอย่างสำหรับ environment ของระบบถูกแยกเก็บตามรีโพซิทอรี และในรีโพซิทอรี Yuuka ยังมีสำเนาตัวอย่างไว้ภายใต้โฟลเดอร์ docs/env เพื่อใช้ประกอบเอกสาร ผู้พัฒนาควรคัดลอกไฟล์ตัวอย่างจากรีโพซิทอรีจริงของแต่ละบริการแล้วปรับค่าให้สอดคล้องกัน

\begin{mycustomenum2}
    \item Midori ใช้ไฟล์ \textbf{midori/.env.example}
    \item Momoi ใช้ไฟล์ \textbf{momoi/.env.example}
    \item Yuzu ใช้ไฟล์ \textbf{yuzu/.env.example}
    \item Satsuki ใช้ไฟล์ environment สำหรับการเชื่อมต่อ PostgreSQL, การสร้างไฟล์ Nginx configuration และการ reload Nginx บนเครื่องภายนอก
\end{mycustomenum2}

\section{ส่วนประกอบหลักของระบบ}
\hspace*{1.3em}
ระบบในฉบับปัจจุบันประกอบด้วยบริการหลักและบริการสนับสนุนที่สัมพันธ์กันดังนี้

\begin{mycustomenum2}
    \item \textbf{Midori} เป็นเว็บแอปพลิเคชันส่วนติดต่อผู้ใช้ พัฒนาด้วย Next.js 16, React 19 และ Tailwind CSS 4
    \item \textbf{Momoi} เป็น API หลักของระบบ พัฒนาด้วย Bun, Elysia.js, Prisma และ better-auth พร้อมเปิดเผย OpenAPI และจัดการเส้นทาง \textbf{/api/auth}
    \item \textbf{Yuzu} เป็น worker service สำหรับงาน provision, deprovision และ toggle status โดยใช้ Redis ร่วมกับ BullMQ เป็นกลไกคิวงาน
    \item \textbf{Satsuki} เป็นบริการ automation บนเครื่อง Nginx ภายนอก สำหรับสร้าง reverse proxy configuration และ \textbf{authorized\_keys}
    \item \textbf{Yuuka} เป็นรีโพซิทอรีสำหรับ Docker Compose, Kubernetes manifests, environment examples และ observability stack
\end{mycustomenum2}

\section{จุดเชื่อมต่อสำคัญในสภาพแวดล้อมพัฒนา}
\hspace*{1.3em}
เมื่อเริ่มบริการครบแล้ว ผู้พัฒนาสามารถเข้าถึงบริการสำคัญได้จากพอร์ตมาตรฐานดังนี้

\begin{mycustomenum2}
    \item Midori ที่ \url{http://localhost:3000}
    \item Momoi ที่ \url{http://localhost:3000}
    \item Grafana ที่ \url{http://localhost:3002}
    \item RustFS Console ที่ \url{http://localhost:9001}
    \item Prometheus ที่ \url{http://localhost:9090}
    \item Jaeger ที่ \url{http://localhost:16686}
\end{mycustomenum2}

\section{การแก้ไขปัญหาเบื้องต้น}
\hspace*{1.3em}
หากพบปัญหาระหว่างการพัฒนา สามารถเริ่มตรวจสอบตามลำดับดังนี้

\begin{mycustomenum2}
    \item \textbf{บริการประกอบเริ่มต้นไม่ได้}
    \begin{mycustomenum2}
        \item ตรวจสอบสถานะด้วยคำสั่ง \textbf{docker compose -f docker/docker-compose.yaml ps}
        \item ดู log ด้วยคำสั่ง \textbf{docker compose -f docker/docker-compose.yaml logs [service\_name]}
        \item รีสตาร์ทบริการด้วยคำสั่ง \textbf{docker compose -f docker/docker-compose.yaml restart [service\_name]}
    \end{mycustomenum2}
    \item \textbf{Frontend ไม่สามารถเชื่อมต่อ API ได้}
    \begin{mycustomenum2}
        \item ตรวจสอบว่า Momoi ทำงานอยู่และเปิดพอร์ตที่กำหนดไว้จริง
        \item ตรวจสอบค่า \textbf{SERVER\_API\_URL} และ \textbf{NEXT\_PUBLIC\_API\_URL} ใน Midori
        \item ตรวจสอบ CORS และ cookie settings ของ Momoi
    \end{mycustomenum2}
    \item \textbf{งาน VM ไม่ถูกประมวลผล}
    \begin{mycustomenum2}
        \item ตรวจสอบ Redis, queue state และ log ของ Yuzu
        \item ตรวจสอบค่า concurrency และ resource lock ที่เกี่ยวข้องกับ \textbf{instanceId} หรือ \textbf{VMID}
        \item ตรวจสอบการเชื่อมต่อไปยัง Proxmox VE
    \end{mycustomenum2}
    \item \textbf{reverse proxy หรือ SSH ใช้งานไม่ได้}
    \begin{mycustomenum2}
        \item ตรวจสอบ log ของ Satsuki บนเครื่อง Nginx ภายนอก
        \item ตรวจสอบไฟล์ reverse proxy configuration และ \textbf{authorized\_keys} ที่ถูกสร้างจริง
        \item ตรวจสอบสถานะการ reload ของ Nginx
    \end{mycustomenum2}
\end{mycustomenum2}
