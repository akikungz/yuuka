\section{การเริ่มต้นใช้งาน}
\hspace*{1.3em}
ภาคผนวกนี้สรุปขั้นตอนการใช้งาน FITM Cloud ผ่านหน้า Dashboard (Midori) สำหรับผู้ใช้งานทุกบทบาท (Student / Instructor / Admin) โดยเน้นลำดับการใช้งานแบบรวดเร็วและกรณีที่พบบ่อย

\begin{mycustomenum2}
    \item เข้าสู่ระบบที่ \textbf{/login}
    \item ไปที่ \textbf{Dashboard \textrightarrow Settings} เพื่อตรวจสอบ \textbf{Role} ของบัญชี
    \item ใน \textbf{Settings \textrightarrow SSH Keys} เพิ่ม SSH public key อย่างน้อย 1 key
    \item (Student) ไปที่ \textbf{Dashboard \textrightarrow Requests \textrightarrow New Request} เพื่อส่งคำขอสร้าง instance
    \item เมื่อคำขอได้รับอนุมัติและ provision เสร็จ ให้ไปที่ \textbf{Dashboard \textrightarrow Instances} เลือก instance แล้วใช้ \textbf{IP address} เพื่อเชื่อมต่อด้วย SSH
\end{mycustomenum2}

\section{การตั้งค่า Reverse Proxy}
\hspace*{1.3em}
Reverse proxy ใช้สำหรับเปิดเผยบริการที่รันอยู่ภายใน VM (เช่น web app ที่พอร์ต 3000) ออกสู่ภายนอกผ่าน HTTP/HTTPS

\vspace{0.5em}
\textbf{Create a reverse proxy}
\vspace{0.5em}

\begin{figure}[H]
\centering
\adjustbox{frame, width=0.9\textwidth}{
    \includegraphics[width=\textwidth]{Image/web/dashboard/captured/reverse_proxies.png}
}
\caption{\fontSixTeen{ภาพหน้าจอการสร้างและกำหนดค่า Reverse Proxy}} 
\label{figI:ReverseProxyPlaceholder}
\end{figure}

\begin{mycustomenum2}
    \item ไปที่ \textbf{Dashboard \textrightarrow Instances \textrightarrow (select an instance) \textrightarrow Reverse Proxies}
    \item เพิ่ม proxy โดยระบุ:
    \begin{mycustomenum2}
        \item \textbf{Target port}: พอร์ตที่แอปของคุณฟังอยู่ใน VM (เช่น 3000)
        \item \textbf{Type}: HTTP หรือ TCP (สำหรับบริการที่ไม่ใช่ HTTP)
        \item \textbf{Description} (ถ้ามี)
    \end{mycustomenum2}
\end{mycustomenum2}

\vspace{0.5em}
\textbf{Delete a reverse proxy}
\vspace{0.5em}

\begin{mycustomenum2}
    \item ลบ proxy ที่ไม่ใช้งานแล้วเพื่อลดความเสี่ยงการเปิดเผยบริการเกินจำเป็น
\end{mycustomenum2}

\vspace{0.5em}
\textbf{การเข้าถึงบริการแบบ TCP Reverse Proxy ด้วย TLS Tunneling}
\vspace{0.5em}

\hspace*{1.3em}
สำหรับบริการที่ไม่ใช่ HTTP/HTTPS โดยตรง เช่น database, IDE remote server, custom TCP service หรือ web application ที่ต้องการส่งผ่านทราฟฟิกแบบดิบ (raw TCP) ระบบสามารถเปิดเผยปลายทางผ่าน TCP reverse proxy ของคลัสเตอร์ได้ โดยใน implementation ปัจจุบันจะใช้ชื่อปลายทางในรูปแบบ \textbf{p\textless port\textgreater-\textless instance-hostname\textgreater.fitm.cloud} แล้วรับทราฟฟิกด้วย TLS จากภายนอกก่อนส่งต่อไปยังพอร์ตภายในของ instance

\hspace*{1.3em}
ตัวอย่างเช่น หาก instance ชื่อ \textbf{vm-01} เปิดบริการที่พอร์ต \textbf{8443} ชื่อปลายทางของ TCP reverse proxy อาจอยู่ในรูปแบบ \textbf{p8443-vm-01.fitm.cloud} จากนั้นผู้ใช้สามารถสร้าง local tunnel ไปยังปลายทางดังกล่าวเพื่อให้โปรแกรมฝั่งเครื่องตนเองเชื่อมต่อผ่าน \textbf{localhost} ได้

\vspace{0.5em}
\textbf{ตัวอย่างด้วย ncat}
\vspace{0.5em}

\hspace*{1.3em}
กรณีที่เครื่องมือฝั่ง client ไม่สามารถเชื่อมต่อ TLS tunnel โดยตรงหรือไม่สะดวกในการกำหนด host ปลายทาง ให้เปิด local listener ด้วย \textbf{ncat} แล้ว forward ต่อไปยัง reverse proxy ภายนอก

\begin{figure}[H]
\centering
\adjustbox{frame, width=0.95\textwidth}{
    \begin{minipage}{0.9\textwidth}
        \texttt{\footnotesize
        ncat -l 127.0.0.1 18443 --keep-open --sh-exec "ncat --ssl p8443-vm-01.fitm.cloud 443"
        }
    \end{minipage}
}
\caption{\fontSixTeen{ตัวอย่างการเปิด local TLS tunnel ด้วย ncat}}
\label{figI:TcpTunnelNcat}
\end{figure}

\begin{mycustomenum2}
    \item เครื่องจะเปิด listener ที่ \textbf{127.0.0.1:18443}
    \item ทุกการเชื่อมต่อที่เข้ามายังพอร์ตนี้จะถูกส่งต่อผ่าน TLS ไปยัง \textbf{p8443-vm-01.fitm.cloud:443}
    \item จากนั้นให้โปรแกรมของคุณชี้ไปยัง \textbf{localhost:18443} แทนการเรียกปลายทางภายนอกโดยตรง
    \item ควรใช้ชื่อ host ปลายทางจริงแทน \textbf{p8443-vm-01.fitm.cloud} ให้ตรงกับ instance และพอร์ตที่ได้รับจากระบบ
\end{mycustomenum2}

\hspace*{1.3em}
หมายเหตุ: พฤติกรรมของ \textbf{ncat} อาจแตกต่างกันตามเวอร์ชันและแพลตฟอร์ม หากสภาพแวดล้อมของผู้ใช้ต้องการการควบคุม TLS/SNI ชัดเจนกว่าค่า default แนะนำให้ใช้ \textbf{socat} หรือ \textbf{stunnel} แทน

\vspace{0.5em}
\textbf{ตัวอย่างด้วย socat}
\vspace{0.5em}

\begin{figure}[H]
\centering
\adjustbox{frame, width=0.95\textwidth}{
    \begin{minipage}{0.9\textwidth}
        \texttt{\footnotesize
        socat TCP-LISTEN:18443,bind=127.0.0.1,fork OPENSSL:p8443-vm-01.fitm.cloud:443,verify=0,snihost=p8443-vm-01.fitm.cloud
        }
    \end{minipage}
}
\caption{\fontSixTeen{ตัวอย่างการเปิด local TLS tunnel ด้วย socat}}
\label{figI:TcpTunnelSocat}
\end{figure}

\hspace*{1.3em}
\textbf{socat} เหมาะกับกรณีที่ต้องการกำหนด \textbf{SNI} ชัดเจน หรือใช้กับ client application ที่ต้องเชื่อมต่อไปยัง \textbf{localhost} อย่างต่อเนื่อง

\vspace{0.5em}
\textbf{ตัวอย่างด้วย stunnel}
\vspace{0.5em}

\hspace*{1.3em}
สำหรับผู้ใช้ที่ต้องการ service tunnel แบบถาวรหรือใช้งานบนเครื่องผู้ใช้ในระยะยาว สามารถใช้ \textbf{stunnel} โดยสร้างไฟล์ตั้งค่าตัวอย่างดังนี้

\begin{figure}[H]
\centering
\adjustbox{frame, width=0.95\textwidth}{
    \begin{minipage}{0.9\textwidth}
        \texttt{\footnotesize
        [fitm-tcp-tunnel]\\
        client = yes\\
        accept = 127.0.0.1:18443\\
        connect = p8443-vm-01.fitm.cloud:443\\
        sni = p8443-vm-01.fitm.cloud\\
        verifyChain = no
        }
    \end{minipage}
}
\caption{\fontSixTeen{ตัวอย่างไฟล์ตั้งค่า stunnel สำหรับ TCP reverse proxy}}
\label{figI:TcpTunnelStunnel}
\end{figure}

\begin{mycustomenum2}
    \item บันทึกไฟล์ตั้งค่าข้างต้น เช่น \textbf{fitm-tunnel.conf}
    \item เริ่มต้น \textbf{stunnel} ด้วยไฟล์ดังกล่าว
    \item ให้โปรแกรมปลายทางเชื่อมต่อมาที่ \textbf{127.0.0.1:18443}
\end{mycustomenum2}

\vspace{0.5em}
\textbf{แนวทางเลือกเครื่องมือ}
\vspace{0.5em}

\begin{mycustomenum2}
    \item ใช้ \textbf{ncat} เมื่อต้องการทดสอบเร็วและเปิด tunnel ชั่วคราวจาก command line
    \item ใช้ \textbf{socat} เมื่อต้องการกำหนดค่า TLS/SNI ให้ชัดเจนและทำงานกับ client ทั่วไปได้ง่าย
    \item ใช้ \textbf{stunnel} เมื่อต้องการ tunnel แบบถาวรหรือรันเป็น background service บนเครื่องผู้ใช้
\end{mycustomenum2}

\section{การแก้ไขปัญหาเบื้องต้น}
\hspace*{1.3em}

\label{figI:TroubleshootPlaceholder}
\end{figure}

\vspace{0.5em}
\textbf{I can’t create a request}
\vspace{0.5em}

\begin{mycustomenum2}
    \item มักเกิดจาก role ไม่มี permission \textbf{CREATE\_REQUEST} หรือไม่มี course offerings ที่ active
    \item ตรวจสอบ role ใน \textbf{Settings} และติดต่อ admin หากข้อมูลบัญชีไม่ถูกต้อง
\end{mycustomenum2}

\vspace{0.5em}
\textbf{No Courses Available}
\vspace{0.5em}

\begin{mycustomenum2}
    \item ไม่มี course offerings ที่เปิดใช้งาน หรือบัญชีของผู้ใช้ไม่สามารถเห็นรายวิชาได้
    \item แนะนำให้ติดต่อผู้สอนหรือผู้ดูแลระบบ
\end{mycustomenum2}

\vspace{0.5em}
\textbf{Approved but no instance yet}
\vspace{0.5em}

\begin{mycustomenum2}
    \item การ provision เป็นงาน asynchronous ให้รอสักครู่และ refresh หน้า \textbf{Instances}
    \item หากค้างนานผิดปกติ ให้ผู้สอน/admin ตรวจสอบสถานะ request และระบบคิวเบื้องหลัง
\end{mycustomenum2}

\vspace{0.5em}
\textbf{SSH connection refused / timed out}
\vspace{0.5em}

\begin{mycustomenum2}
    \item ตรวจสอบว่า instance อยู่สถานะ \textbf{Active} และ IP Address ถูกต้อง
    \item ตรวจสอบว่าเพิ่ม SSH key แล้วใน \textbf{Settings \textrightarrow SSH Keys}
    \item หาก template หรือ firewall ปิด SSH ให้ติดต่อผู้สอน/admin
\end{mycustomenum2}

\vspace{0.5em}
\textbf{Can’t see reverse proxy / audit log tabs}
\vspace{0.5em}

\begin{mycustomenum2}
    \item role อาจไม่มี permission ที่เกี่ยวข้อง หรือ instance อยู่ในสถานะที่ feature ยังไม่พร้อม
\end{mycustomenum2}

\vspace{0.5em}
\textbf{TCP reverse proxy เชื่อมต่อไม่ได้ หรือ TLS tunnel ใช้งานไม่ได้}
\vspace{0.5em}

\begin{mycustomenum2}
    \item ตรวจสอบว่าใช้ชื่อปลายทางถูกต้องตามรูปแบบ \textbf{p\textless port\textgreater-\textless instance-hostname\textgreater.fitm.cloud}
    \item ตรวจสอบว่าพอร์ตภายในของบริการใน instance เปิดใช้งานอยู่จริงและฟังบน interface ที่ถูกต้อง
    \item หากใช้ \textbf{ncat} แล้วเชื่อมต่อไม่สำเร็จ ให้ลองเปลี่ยนไปใช้ \textbf{socat} หรือ \textbf{stunnel} เพื่อกำหนดค่า TLS/SNI ชัดเจนขึ้น
    \item ตรวจสอบว่า firewall, security group หรือ network policy ไม่ได้บล็อกการเข้าถึงพอร์ตภายนอก \textbf{443}
    \item หาก reverse proxy ถูกสร้างแล้วแต่ยังใช้งานไม่ได้ ให้ผู้ดูแลตรวจสอบ Satsuki, ไฟล์ Nginx stream configuration บนเครื่อง reverse proxy ภายนอก และสถานะ reload ของ Nginx หน้าด่าน
\end{mycustomenum2}

\section{คำศัพท์สำคัญ}
\hspace*{1.3em}

\begin{mycustomenum2}
    \item \textbf{Instance}: เครื่องเสมือน (VM) ที่ระบบจัดสรรให้ผู้ใช้งาน/รายวิชา
    \item \textbf{Template}: OS image สำหรับสร้าง instance (เช่น Ubuntu, Debian)
    \item \textbf{Request}: คำขอสร้าง instance ที่ต้องผ่านการพิจารณา
    \item \textbf{Extended Request}: คำขอขยายอายุการใช้งานของ instance
    \item \textbf{Promote}: การกำหนดให้ instance เป็น long-term ตามนโยบาย
    \item \textbf{Reverse Proxy}: การแมป URL ภายนอกไปยังพอร์ตของบริการใน instance ผ่าน HTTP/HTTPS
\end{mycustomenum2}
